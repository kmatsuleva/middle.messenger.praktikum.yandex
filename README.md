# Мессенджер

Веб-приложение для общения в реальном времени, построенное на TypeScript, Handlebars и Vite.

## Возможности

- Регистрация и вход в систему
- Список чатов с лентой переписки
- Управление профилем (редактирование данных, смена пароля, обновление аватара)
- Страницы ошибок (404, 500)

## Технологии

- **TypeScript**
- **Handlebars** — шаблонизатор
- **SCSS** — стили с переменными и миксинами
- **Vite** — сборщик

## Начало работы

### Требования

- Node.js >= 22

### Установка

```bash
npm install
```

### Команды

| Команда         | Описание                                 |
| --------------- | ---------------------------------------- |
| `npm run start` | Собрать и запустить проект на порту 3000 |
| `npm run dev`   | Запустить сервер разработки              |
| `npm run build` | Собрать проект для продакшна             |
